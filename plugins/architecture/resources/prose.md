# Architecture Prose Instructions

Architecture artifacts are read by stakeholders and by developers new to the system, not only
by architects.

- Write sentences a stakeholder would say out loud. Prefer the plain word over the pattern
  name wherever both fit, and define a pattern name on first use where the structure needs it.
- Short sentences, active voice, present tense. No filler, no hedging, no restating the
  heading in the first line under it.
- Say each thing once. Link to the section, decision record, or debt record that already
  covers a term, decision, or constraint instead of repeating it.
- Drop a section that has nothing to say rather than writing that it has nothing.
- A diagram carries the structure; the prose beside it carries what the diagram cannot show —
  why it is this way, and what to watch out for. Never narrate the boxes in text.
