# GitHub Profile Instructions

This contract governs GitHub profile content — profile README drafts, public profile
summaries, highlight pages — for collaborators, recruiters, maintainers, and developers
visiting the profile. The shared procedure is [document-authoring.md](document-authoring.md).

## Structure

1. `# Title` — name, handle, or positioning line.
2. `## Overview` — short hook: what you build and for whom, in the first paragraph.
3. `## Focus Areas` — technologies, domains, or problem spaces.
4. `## Highlights` — selected achievements, each with a link or proof.
5. `## Selected Projects` — 1-3 projects with one-line value statements.
6. `## Collaboration` — how people can follow up, collaborate, or explore more.

## Writing Rules

- Lead with current value and direction, not full biography.
- Prefer proof links and outcome-oriented bullets; use metrics or lessons where they add
  credibility.
- Back every claim with public proof; leave out superlatives nothing supports.
- Use emojis sparingly, and only where they improve scanning.
