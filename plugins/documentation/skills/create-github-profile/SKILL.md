# Create GitHub Profile

Write or refresh a public GitHub profile: a clear hook, proof links, and a collaboration path.

Before drafting, read [document-authoring.md](../../resources/document-authoring.md) and run
its procedure with:

- **Inputs:** the profile focus, the audience it speaks to, and the proof to highlight
  (repositories, demos, talks, or posts).
- **Type contract:** [profile-github.md](../../resources/profile-github.md).
- **Default path:** `profiles/github/`.

Deliver one Markdown GitHub profile ready for review or publication.
