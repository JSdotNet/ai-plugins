# Create Idea

Capture an emerging idea quickly, with just enough structure to evaluate and refine it.

Before drafting, read [document-authoring.md](../../resources/document-authoring.md) and run
its procedure with:

- **Inputs:** a short, outcome-oriented working title, the problem (the pain point or
  opportunity), the audience (who benefits), and the value hypothesis (the outcome expected
  if the idea is implemented).
- **Type contract:** [ideas.md](../../resources/ideas.md).
- **Default path:** `documents/ideas/`, the file named per ideas.md.

Deliver one Markdown Idea ready for team review or refinement.
