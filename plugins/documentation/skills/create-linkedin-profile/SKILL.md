# Create LinkedIn Profile

Write or refresh a LinkedIn profile: specific positioning, concise proof, and a call to action.

Before drafting, read [document-authoring.md](../../resources/document-authoring.md) and run
its procedure with:

- **Inputs:** the positioning (role, domain, or strengths to stand out), the audience it
  should attract, the proof (outcomes, achievements, or links), and the call to action.
- **Type contract:** [profile-linkedin.md](../../resources/profile-linkedin.md).
- **Default path:** `profiles/linkedin/`.

Deliver one Markdown LinkedIn profile ready for review or publication.
